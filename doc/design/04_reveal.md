# 04 · 信息揭露系统

> 本文档定义《Agamemnon》的核心信息系统——玩家如何获取仓库物品的信息。

---

## 一、设计核心

### 1.1 设计哲学

> **揭露是本游戏的唯一"硬通货"。**
>
> 金币无限，但揭露机会有限。玩家的策略深度来自"如何最大化每次揭露的信息价值"。

### 1.2 两个维度

信息揭露有两个维度：
- **揭露了哪里**（空间维度）：仓库的哪些格子被揭露
- **揭露了什么**（层级维度）：揭露了物品的什么信息

---

## 二、揭露层级（信息深度）

### 2.1 五个层级

从看不见到看全部，共 5 个层级：

| Level | 名称 | 视觉 | 玩家获得的信息 |
|-------|------|------|--------------|
| L0 | 未揭露 | ░░ 深灰盲格 | 完全看不见 |
| L1 | 存在性 | ▓▓ 浅灰格 | 知道这里有物品（暗示尺寸） |
| L2 | 类别 | 📦 类别图标 | 知道是"武器/家具/艺术品..."类别 |
| L3 | 品质 | 🟪 品质颜色 | 知道是"紫色品质"（价值区间已知） |
| L4 | 全揭露 | ⚔ 图标+颜色 | 知道精确名称和真实价值 |

### 2.2 层级叠加

L2（类别）和 L3（品质）**可叠加**：
- L2 + L3 = "紫色武器"（双重信息，价值估算大幅精确化）
- L2 单独 = "武器"（不知品质，可能白可能红）
- L3 单独 = "紫色"（不知类别，可能是画可能是剑）

**视觉呈现**：
```
L2 only:    📦 (灰色类别图标)
L3 only:    🟪 (纯色块)
L2+L3:      🟪📦 (紫色+武器图标)
L4:         🟪⚔ (紫色+物品图标+tooltip)
```

### 2.3 层级对估值精度的影响

以一个 **2×2 真实值 350 的蓝色物品**为例：

| 获得层级 | 玩家估值空间 | 估值精度 |
|---------|-------------|---------|
| L0 | 不知道存在 | 0% |
| L1 | "有个 2×2 物品" → 估值 50~3000 | 10% |
| L2（武器） | "2×2 武器" → 估值 50~1500 | 20% |
| L3（蓝色） | "2×2 蓝色物品" → 估值 150~600 | 50% |
| L2+L3 | "2×2 蓝色武器" → 估值 200~500 | 75% |
| L4 | "精确价值 350" | 100% |

## 三、揭露空间（揭露哪里）

### 3.1 揭露粒度

揭露以"格子"为最小单位：
- 揭露一个物品的**任意一格** = 揭露整个物品
- 物品的所有格子共享同一个揭露层级
- 不同玩家各自维护"已揭露格子集合"

### 3.2 谁能看到

**重要原则**：**每个玩家维护自己的"已揭露物品视图"**。

```
玩家 A 的视图:              玩家 B 的视图:
┌──────────────┐            ┌──────────────┐
│ ░░⚔░░░░🟪░░ │            │ ░░░░░📦░░░░░ │
│ ░░⚔░░░░🟪░░ │            │ ░░░░░📦░░░░░ │
│ ░░░░░░░░░░░ │            │ 🟪░░░░░░░░░░ │
│ ░░░░░░░░🟪░ │            │ 🟪░░░░░░░░░░ │
└──────────────┘            └──────────────┘

同一个仓库，不同玩家看到的已揭露内容不同！
```

### 3.3 揭露的永久性

> ⭐ **关键机制**：揭露在**整局游戏（所有回合）内永久有效**。

- 第 1 回合揭露的 A 格，第 2 ~ 10 回合仍然可见
- 揭露只会**增加**，不会**减少**（除非特殊技能）
- 越到后期，玩家掌握的信息越多 → 对应后期倍率降低

### 3.4 揭露顺序的影响

**揭露的时机很重要**：
- 前期（回合 1~2）揭露 = 可用于前期激进出价
- 后期（回合 6~10）揭露 = 只能用于精准补刀

**设计巧思**：
- 有的英雄/天赋前期揭露多（占卜师）
- 有的英雄/天赋后期加速揭露（学者的后期叠加）
- 创造"选择英雄 = 选择节奏"的战略维度

## 四、揭露来源

### 4.1 四类揭露来源

| 来源 | 触发方式 | 数量 | 可控性 |
|------|---------|------|--------|
| **英雄被动** | 每回合自动 | 3~10 格 | 位置随机/规则固定 |
| **天赋被动** | 开局或每回合自动 | 1~5 格 | 位置随机/规则固定 |
| **主动技能** | 玩家手动使用 | 1~5 格 | 位置由玩家指定（⭐可控） |

### 4.2 被动揭露的规则示例

**占卜师的被动**：每回合随机揭露 5 格的 L3（品质）
```
算法：
1. 取尚未 L3+ 揭露的格子集合
2. 随机选 5 格
3. 应用 L3 揭露
```

**鹰眼的被动**：每回合揭露一整行 10 格的 L3（行号随机）

```
算法：
1. 随机选一行（1~200）
2. 对该行 10 个格子全部应用 L3 揭露
```

### 4.3 主动技能的规则示例

**占卜师的主动"天眼"**（CD 2 回合）：
```
选择任意 1 格 → 应用 L4 全揭露
```

**学者的主动"盘点"**（CD 2 回合）：
```
不选格子 → 显示"全仓库品质分布"
  例如："本仓库：白 120, 绿 50, 蓝 20, 紫 5, 黄 2, 红 1"
```

## 五、信息持久化实现

### 5.1 数据结构

```
Player {
  revealed_cells: Dict<(row,col), RevealLevel>
  # 记录该玩家已揭露的每个格子的最高层级
}

当新揭露发生：
  current = player.revealed_cells.get((r,c), L0)
  new = max(current, applied_level)
  player.revealed_cells[(r,c)] = new
```

### 5.2 展示合并

显示时：
```
对于格子 (r,c)：
  level = player.revealed_cells[(r,c)]
  IF level == L0: 渲染为盲格
  IF level >= L1: 渲染为该物品对应的视觉（按 level 决定细节）
```

## 六、信息估值权重

### 6.1 估值贡献表

玩家根据揭露层级估算物品价值时的参考：

| 层级 | 估值方式 | 估值精度 |
|------|---------|---------|
| L0 | 不计入估值 | - |
| L1 | 按平均价值 = (尺寸 × 平均系数 × 默认扰动) | ±70% |
| L2 | 按该类别的平均价值 | ±50% |
| L3 | 按该品质的中位数价值 | ±30% |
| L2+L3 | 按类别×品质的中位数 | ±15% |
| L4 | 精确值 | ±0% |

### 6.2 AI 估值的数学模型

```
for item in 已揭露物品:
    if item.level == L4:
        estimated = item.true_value
    elif item.level == L2+L3:
        estimated = median(category, quality) × random(0.85, 1.15)
    elif item.level == L3:
        estimated = median(quality) × random(0.7, 1.3)
    ...
    total_known += estimated

# 推算未揭露部分
revealed_ratio = len(revealed_cells) / 2000
estimated_total = total_known / revealed_ratio

# 加入 AI 的个性扰动
estimated_total *= random(1 - ai.error, 1 + ai.error)
```

详见 [`08_ai.md`](./08_ai.md)。

## 七、揭露与回合倍率的策略博弈

### 7.1 信息量随回合变化

```
回合   |  预期累积揭露量  |  倍率要求
───────┼─────────────────┼──────────
 1     |    5~15 格       |  2.0× (极难满足)
 2     |   10~25 格       |  1.6×
 3     |   15~40 格       |  1.3×
 4     |   20~55 格       |  1.1×
 5     |   25~70 格       |  1.0×
 6~10  |   30~120 格      |  1.0×
```

### 7.2 策略空间

**策略 A：前期激进** (Round 1~2 出高价)
```
优势：对手信息更少，更保守
劣势：自己估值也不准，容易砸手
适合：高估值能力的玩家 + 激进型英雄
```

**策略 B：中期发力** (Round 3~5 发起攻击)
```
优势：信息累积+倍率合理
劣势：最主流被对标
适合：大多数玩家
```

**策略 C：末局决胜** (Round 6~10 精确狙击)
```
优势：估值最准
劣势：前面可能已被抢走（本局没拍下 = 全局 0 分）
适合：稳健玩家 + 后期增益英雄
```

## 八、特殊揭露机制（进阶）

### 8.1 假信息 (Fake Info)

某些英雄/天赋可以：
- **生成假信息**：看起来揭露了 L4，但内容是假的（骗子英雄）
- **识别假信息**：有"火眼金睛"天赋可以看穿

**实现**：
```
Player.revealed_cells[(r,c)] = {level: L4, is_fake: True, fake_value: 5000}
显示时看起来是 L4，但实际计算时仓库真实值不变
```

### 8.2 共享信息

- 某些天赋允许队友共享揭露（但 Demo 阶段 1v3 AI，不涉及队友）
- 联机版 2v2 模式可能用到

### 8.3 抹除信息

- 赌徒英雄的主动"混乱"：随机抹掉 3 格已揭露信息
- 打击对手的累积优势

### 8.4 趋势信息

- 学者的"盘点"不揭露具体格子，而是给出"品质分布直方图"
- 提供宏观视角而不暴露细节

## 十、Demo 阶段简化

**Demo 阶段的揭露系统**：

### ✅ 保留
- 5 个揭露层级（L0~L4）
- 层级叠加
- 信息持久化
- 英雄被动 + 主动技能
- 不同玩家各自的已揭露视图

### ❌ 暂不做
- 假信息机制（骗子英雄延后）
- 信息抹除机制
- 天赋系统（先只做英雄被动+主动）
- 线索卡

### 🎯 Demo 的 3 个测试英雄（预览）

| 英雄 | 被动 | 主动 | CD |
|------|------|------|---|
| 占卜师 | 每回合随机 5 格 L3 | 指定 1 格 L4 | 2 |
| 鹰眼 | 每回合一整行 L3 | 指定 1 列 L2 | 3 |
| 学者 | 每回合随机 3 格 L4 | 查看品质分布 | 2 |
