## 四、美术风格方向

### 4.1 视觉关键词

- **中式古典感**（从你的参考图推断）：榫卯、青铜、玉石、古籍
- **神秘感**：拍卖的博弈氛围
- **现代简约 UI**：避免过度装饰干扰信息判断

### 4.2 配色方案（草案）

```
主色调：深棕色 (#2D1810)      背景
辅助色：金色   (#D4AF37)      高光 / 重要元素
点缀色：翠绿   (#4A7C59)      积极反馈
警示色：朱红   (#B22222)      掉分 / 警告

品质色（不可改）：
  白 #CCCCCC
  绿 #4ADE80
  蓝 #3B82F6
  紫 #A855F7
  黄 #FBBF24
  红 #EF4444
```

### 4.3 字体建议

- **标题**：思源宋体（中式）
- **正文**：思源黑体（现代）
- **数字**：等宽字体（如 Noto Sans Mono，方便读金额）

## 五、HTML 原型计划

### 5.1 为什么用 HTML 原型？

1. 可以**真实交互**（悬浮 tooltip、滚动、点击）
2. 可以**快速迭代**设计
3. 可以**在浏览器打开**就能预览，不需要构建 Godot
4. 可以**作为美术/UE 的参考稿**

### 5.2 原型文件结构

```
doc/design/ui_prototype/
├── index.html              主菜单
├── hero_select.html        英雄选择
├── auction_room.html       ⭐ 拍卖房核心
├── settlement.html         结算页
├── assets/
│   ├── style.css
│   ├── warehouse.css       仓库面板专用
│   └── mock_data.js        模拟数据
└── README.md
```

### 5.3 原型目标

- ✅ 展示完整视觉风格
- ✅ 实现仓库面板的滚动和悬浮交互
- ✅ 模拟揭露状态的 5 种视觉
- ✅ 实现出价输入和倒计时
- ❌ 不需要真实的游戏逻辑（用硬编码数据即可）
- ❌ 不需要联网功能

## 六、交互细节（核心）

### 6.1 仓库面板交互

| 操作 | 触发事件 |
|------|---------|
| 鼠标悬浮格子 | 显示 tooltip（根据揭露层级） |
| 点击格子 | 若当前英雄有"点击揭露"主动 → 揭露该格 |
| 滚轮滚动 | 垂直滚动 |
| 按住拖拽 | 快速滚动 |
| Home/End | 跳转顶/底 |
| Ctrl+F | 搜索已揭露物品（按品质/类别） |

### 6.2 技能使用流程

```
1. 点击左侧"主动技能"按钮
2. 按钮进入"待指定"状态
3. 鼠标变为特殊光标（指定目标）
4. 点击仓库格子 → 应用技能
5. 技能进入冷却，显示剩余 CD
```

### 6.3 出价输入流程

```
1. 揭露阶段结束，自动切换到出价阶段
2. 出价面板弹出，输入框自动聚焦
3. 玩家输入数字（支持键盘快捷键）
4. 点击"锁定出价"或按回车 → 提交
5. 锁定后不可更改，等待其他玩家
6. 全部锁定后立即判定（或等待倒计时结束）
```

## 七、Demo 阶段 UI 简化

### 7.1 最小可行 UI

Demo 阶段**不需要精美美术**，核心是**功能完整 + 清晰可读**：

- ✅ 仓库面板用 Godot 原生 GridContainer / Control
- ✅ 格子用纯色 ColorRect + Label（显示尺寸或图标）
- ✅ 字体用系统默认
- ✅ 动画极简（淡入淡出即可）
- ❌ 不需要背景音乐、音效
- ❌ 不需要粒子特效
- ❌ 不需要 3D 元素

### 7.2 Demo UI 优先级

| 优先级 | 界面 | 说明 |
|--------|------|------|
| P0 | 仓库面板 | 核心可交互组件 |
| P0 | 出价面板 | 输入金额 |
| P0 | 英雄技能面板 | 显示 CD，点击释放 |
| P0 | 结算页 | 显示真值和分数变动 |
| P1 | 英雄选择 | 简化版：3 个按钮 |
| P1 | 主菜单 | 就 2 个按钮："开始" / "退出" |
| P2 | 段位/排行榜 | Demo 暂不做 |
