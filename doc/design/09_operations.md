# 09 · 运营规划

> 本文档定义《Agamemnon》上线后的长期运营策略。

---

## 一、赛季系统

### 1.1 赛季节奏

```
每个赛季 = 3 个月 (约 90 天)
一年 = 4 个赛季

赛季时间表：
  第 1 周      赛季开启 + 新英雄/新主题公布
  第 2~11 周   主赛程
  第 12 周     赛季末冲刺 + 最终排名
  赛季结束     分数软重置 + 奖励发放 + 新赛季预热
```

### 1.2 赛季软重置算法

```
new_score = 1000 + (current_score - 1000) × 0.3

举例：
  2500 分 → 1000 + 1500 × 0.3 = 1450
  1800 分 → 1000 + 800 × 0.3 = 1240
  800 分  → 1000 + (-200) × 0.3 = 940
  3500 分 → 1000 + 2500 × 0.3 = 1750

原则：
  - 高段位玩家回归均值但仍领先
  - 低段位玩家不会变得更低
  - 所有人需要重新冲段位，但起跑线不同
```

### 1.3 赛季主题

每赛季一个文化主题，影响：
- 仓库物品的视觉风格
- 限定皮肤
- 新英雄
- UI 装饰

**赛季主题排期（示例）**：

| 赛季 | 主题 | 关键内容 |
|------|------|---------|
| S1 | 古董珍玩（默认） | 基础文化古董 |
| S2 | 海盗宝藏 | 海盗英雄、宝箱仓库 |
| S3 | 星际考古 | 太空英雄、外星物品 |
| S4 | 东方瑰宝 | 中式英雄、古玩精品 |
| S5 | 神话传说 | 神话英雄、传奇物品 |
| S6 | 末世废墟 | 幸存者英雄、废土物品 |

## 二、内容更新节奏

### 2.1 更新类型与频率

| 更新类型 | 频率 | 内容 |
|---------|------|------|
| 紧急修复 | 按需 | 崩溃/严重 bug |
| 平衡补丁 | 每 2 周 | 英雄/天赋数值微调 |
| 内容补丁 | 每月 | 新物品 20~30 个、新皮肤 |
| 大版本 | 每季度 | 新英雄 1~2 个、新天赋 3~5 个 |
| 年度版本 | 每年 | 新模式 / 新机制 |

### 2.2 新英雄发布节奏

```
每赛季开始时 → 发布 1 个新英雄
  第 1 周：仅限通行证购买者试用
  第 2 周：所有人可用（通行证者继续保留专属皮肤）

每年发 4 个新英雄 + 老英雄 Rework

3 年后：预期有 18~24 个英雄
```

### 2.3 物品池扩充

```
Demo  版本：20~30 个物品
Alpha 版本：100 个物品
Beta  版本：300 个物品
正式  上线：500+ 个物品
每月  扩充：+20~30 个
```

## 三、玩家留存策略

### 3.1 每日任务

```
每日任务（3 项，每天重置）：
  ✓ 完成 3 局游戏 → 奖励 100 经验
  ✓ 使用 2 个不同英雄 → 奖励 50 金币
  ✓ 揭露 100 格盲区 → 奖励通行证积分

全部完成 → 额外礼包（随机皮肤碎片）
```

### 3.2 周任务

```
每周任务（5 项，每周一重置）：
  ✓ 本周达到指定积分 → 头像框
  ✓ 赢下 5 局 → 皮肤碎片
  ✓ 使用 3 个不同英雄至少各赢 1 局 → 通行证大奖
  ✓ 单局精准估值 (偏差 < 5%) → 专属头像
  ✓ 最高段位冲击奖励 → 金色边框
```

### 3.3 成就系统

分为 **累积成就** 和 **技巧成就**：

#### 累积成就
- "千锤百炼"：完成 1000 局
- "见多识广"：遇到 500 种不同物品
- "英雄典藏"：所有英雄各赢 10 局

#### 技巧成就
- "神级估值"：单局偏差 < 1%
- "全员流拍"：一局中诱使对手全流拍一次
- "逆风翻盘"：-20 分后单局打回 +15 分
- "末局之王"：在第 10 回合拍下并赢分

### 3.4 连续登录奖励

```
连续 7 天登录 → 通行证 Tier 5 解锁
连续 30 天登录 → 限定头像
连续 100 天 → 限定英雄皮肤（永久）
```

## 四、社交功能

### 4.1 好友系统

- 赛后可一键加好友
- 好友列表最多 200 人
- 好友在线状态显示
- 邀请好友同队/同房

### 4.2 战队系统（S2 上线）

- 每战队最多 50 人
- 战队积分榜
- 战队战：每周定时的跨战队对抗

### 4.3 观战系统（S3 上线）

- 可观战好友
- 可观战排行榜 Top 10 玩家
- 观战者看不到具体揭露内容（防外挂）
- 延迟 30 秒播放

### 4.4 回放系统（S4 上线）

- 自动保存最近 20 局回放
- 可分享回放 URL
- 回放可快进/慢放/暂停
- 可查看各玩家的揭露视图

```

赞助来源：
```

## 七、数据驱动优化

### 7.1 关键指标 (KPI)

| 指标 | 目标值 | 说明 |
|------|--------|------|
| DAU/MAU 比 | > 30% | 活跃度 |
| 留存 D1 | > 45% | 次日留存 |
| 留存 D7 | > 25% | 周留存 |
| 留存 D30 | > 12% | 月留存 |
| 单局时长 | 8~12 分钟 | 符合设计 |
| 完局率 | > 85% | 不中途退出 |
| 平均出价偏差 | < 25% | 玩家整体估值能力 |

### 7.2 数据看板

- 英雄胜率统计 → 调整平衡性
- 天赋使用率 → 识别过强/过弱天赋
- 回合 1~10 的拍下分布 → 优化倍率
- 玩家流失节点 → 改进新手体验

### 7.3 A/B 测试

```
定期对新功能做 A/B 测试：
  - 新平衡补丁：10% 玩家先测试
  - 新界面：5% 玩家先测试
  - 数据分析后再全推
```

## 十、长期运营愿景

### 10.1 3 年目标

- **第 1 年**：达成 10 万月活，建立核心玩家群
- **第 2 年**：电竞化起步，首届官方杯赛
- **第 3 年**：成为"估值策略"游戏的标杆

### 10.2 IP 扩展可能

- **周边衍生品**：艺术画册、桌游版、小说
- **跨界合作**：与实体拍卖行、博物馆联动
- **续作/DLC**：资料片模式、单人剧情模式

### 10.3 生态建设

```
长期目标：
  - 形成玩家 → 主播 → 电竞 → 赛事的完整生态
  - 建立"估值大师"的职业圈
  - 与博物馆/文化机构合作推广文物知识
  (让玩游戏的人顺便学到文化知识)
```
