# 06 · 天赋系统（占位文档）

> ⚠️ 本文档为**占位框架**，详细天赋设计待后续细化。

---

## 一、设计方向（已确定）

### 1.1 天赋的作用

**天赋是对英雄能力的二次定制**。同一英雄选不同天赋 = 不同玩法。

### 1.2 选择规则（草案）

- 每局游戏开局选 **2 个天赋**
- 天赋选定后**本局不可更改**
- 选择时长：30 秒
- 天赋在英雄选择之后再选（这样可以根据英雄特点搭配）

### 1.3 天赋树结构（草案）

分为**三大系**，每系 5~6 个天赋：

```
┌─────────────────────────┐
│     天赋选择界面          │
├─────────────────────────┤
│ 🔍 情报系                │
│   └ 深化揭露的能力        │
│                         │
│ 🧠 心理系                │
│   └ 影响对手 / 出价博弈   │
│                         │
│ ⚡ 专精系                │
│   └ 特定场景的精度加成    │
└─────────────────────────┘

规则：可从任意系各选 2 个（不强制分散）
```

## 二、天赋池（概念草案）

> 以下天赋为**初步构想**，效果和数值待平衡。

### 🔍 情报系

| 天赋 | 效果 | 定位 |
|------|------|------|
| **广域扫描** | 主动技能揭露时，额外揭露周围 4 格 | 加强主动技能 |
| **深度分析** | L3 揭露有 30% 概率升级为 L4 | 被动质量提升 |
| **过目不忘** | 可以保留前一局仓库的部分统计信息（跨局） | 长线玩家 |
| **逻辑推理** | UI 显示"已揭露占仓库比例"精确到 0.1% | 数字党 |
| **火眼金睛** | 可识别假信息（骗子的假揭露） | 反骗子 |
| **预见性** | 开局前看到仓库类型标签（如"聚集仓"） | 前期辅助 |

### 🧠 心理系

| 天赋 | 效果 | 定位 |
|------|------|------|
| **虚张声势** | 你的出价对其他人显示为 ±20% 扰动 | 心理战 |
| **读心术** | 每回合随机看到 1 位对手的出价范围（如"15000~25000"） | 侦察 |
| **赌徒心态** | 当你出价最低时，本回合免除掉分 | 保守保护 |
| **逆风翻盘** | 掉分后的下一回合，额外揭露 3 格 L3 | 翻盘机制 |
| **冷静分析** | 判定阶段前可看到其他玩家**是否已出价** | 节奏掌控 |
| **虚晃一枪** | 第一回合出价时不触发其他玩家的"读心"天赋 | 反侦察 |

### ⚡ 专精系

| 天赋 | 效果 | 定位 |
|------|------|------|
| **品质大师** | 紫/黄/红品质物品的估值精度 +30% | 高品质精确党 |
| **数量大师** | L1 揭露时，额外告知确切尺寸 | 数量党 |
| **大件克星** | 4×4 及以上物品揭露时直接 L4 | 大件猎手 |
| **一锤定音** | 第 10 回合出价精度 +50%（UI 辅助加强） | 末局保险 |
| **快速出价** | 出价阶段节省 5 秒，多的时间可返还给揭露 | 节奏流 |
| **专业鉴定** | 同一物品再次被揭露时，直接升到 L4 | 重复强化 |

## 三、天赋组合推荐（示例）

### 新手组合：稳健路线
- 占卜师 + "深度分析" + "一锤定音"
- 玩法：跟英雄走，靠天赋稳上分

### 进阶组合：激进情报流
- 鹰眼 + "广域扫描" + "预见性"
- 玩法：前期用类型标签+大范围揭露，前 2 回合激进出价

### 高手组合：心理战大师
- 骗子 + "虚张声势" + "读心术"
- 玩法：骗人 + 看穿对手

### 玄学组合：末局抢分
- 学者 + "赌徒心态" + "一锤定音"
- 玩法：前期稳住不掉分，末局一锤定音
