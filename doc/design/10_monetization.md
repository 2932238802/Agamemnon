# 10 · 商业化设计

> 本文档定义《Agamemnon》的收费模式与商业化策略。

---

## 一、核心原则

### 1.1 Pay-to-Customize, Not Pay-to-Win

> **付费内容绝不影响游戏公平性。**

所有可付费物品仅限：
- 外观皮肤
- 头像/头像框
- 动作/特效
- 通行证积分

**绝不卖**：
- ❌ 游戏能力（揭露数量、估值精度）
- ❌ 专属英雄（所有英雄必须免费可用）
- ❌ 加速道具（影响比赛公平）

### 1.2 定价哲学

- **买断制优先**：Steam 买断 + 内购美化
- **不做 F2P**：避免"氪金付费"印象
- **合理定价**：参考同品类游戏 ¥68~98
- **长期价值**：通过美化、通行证产生持续收入

## 二、收费模式

### 2.1 主模式：买断 + 通行证 + 皮肤

```
┌─────────────────────────────┐
│ 第 1 层：买断              │
│ ¥68~98                     │
│ → 解锁全部英雄/天赋/玩法    │
├─────────────────────────────┤
│ 第 2 层：赛季通行证         │
│ ¥68/季                     │
│ → 解锁该季独家奖励          │
├─────────────────────────────┤
│ 第 3 层：外观皮肤           │
│ ¥15~80                     │
│ → 个性化定制                │
├─────────────────────────────┤
│ 第 4 层：纪念品（少量）      │
│ ¥50~200                    │
│ → 收藏向大礼包              │
└─────────────────────────────┘
```

## 四、付费设计原则

### 4.1 避免的商业化陷阱

| 陷阱 | 问题 | 我们的做法 |
|------|------|-----------|
| 能力道具 | 影响公平 | ❌ 绝不卖 |
| 不透明开箱 | 赌博性质 | ❌ 不做开箱，改为直售 |
| 稀释式通行证 | 让人"必须买" | ✅ 通行证主要是美化，不买不影响游戏 |
| 限时 FOMO | 利用焦虑 | ✅ 限时有，但不过分（季度更新为主） |
| 新手墙 | 逼氪 | ❌ 不做，所有玩法免费 |
| 疲劳值 | 逼氪 | ❌ 不做 |

### 4.2 透明度原则

- 所有皮肤在商城明码标价
- 通行证奖励表公开展示
- 无"随机抽奖"的隐藏概率
- 购买前可预览所有内容

### 4.3 消费保护

- 24 小时内可退款（未使用）
- 未成年人消费限额
- 充值记录完整可查
- 单账号月消费上限（防沉迷）

## 五、营收预估

### 5.1 首年目标（保守估计）

```
游戏销量：   100,000 份 × ¥68   = ¥6,800,000
通行证：     30% × 4 季 × ¥68   = ¥816,000 (单位/年，人均)
             100,000 × 30% × 4 × 68 = 8,160,000/年
皮肤：       30% × ¥150/年/人    = ¥4,500,000
纪念品：     10% × ¥200/年/人    = ¥2,000,000

首年总营收目标：约 ¥2,000 万 ~ 2,500 万 (保守)
```

### 5.2 三年预测

| 年份 | 累计销量 | 年活跃玩家 | 年营收 |
|------|---------|-----------|--------|
| 第 1 年 | 10 万 | 5 万 | 2000 万 |
| 第 2 年 | 25 万 | 10 万 | 4500 万 |
| 第 3 年 | 40 万 | 15 万 | 7000 万 |

**三年累计营收目标**：约 1.3 亿

### 5.3 成本与利润

```
开发成本估算（2 年）：
  团队 10 人 × 2 年 × 平均月薪 ¥30,000 = ¥7,200,000
  美术外包：¥2,000,000
  服务器/工具：¥1,000,000
  市场营销：¥3,000,000
  总计：约 ¥1,300 万

运营成本（每年）：
  团队维护：¥3,000,000
  服务器：¥1,000,000
  市场：¥2,000,000
  总计：约 600 万/年

首年利润：2000 - 1300 - 600 = ¥100 万（微盈亏平衡）
第 2 年起：每年净利润 ¥2000+ 万
```

## 六、营销策略

### 6.1 上线前营销

```
T-6 月：首曝光
  - 官网建站
  - Steam 页面上线
  - 首个预告片
  - 开放 Wishlist

T-3 月：封闭测试
  - 邀请 500 名核心玩家
  - 收集反馈
  - 制造稀缺感

T-1 月：Demo 上线
  - Steam Next Fest 参与
  - 免费 Demo 提供
  - KOL 测评送码

T-0：上线
  - 首周 7 折促销 (¥68 → ¥48)
  - Steam 推荐位申请
  - 直播活动
```

### 6.2 上线后营销

- **赛季更新**：每季一个主题版本发布
- **联动合作**：与拍卖行、博物馆的跨界联动
- **赛事直播**：官方赛事吸引流量
- **UGC 激励**：鼓励玩家自发传播

### 6.3 目标受众

```
核心受众：
  - 策略游戏玩家 (17~35 岁)
  - 桌游/狼人杀玩家
  - 扑克/麻将爱好者
  - 竞技游戏爬分党

次要受众：
  - 文化收藏爱好者
  - Indie 游戏粉丝
```

## 七、合规与法务

### 7.1 中国大陆合规

- 软著、版号申请
- 未成年人防沉迷（人脸识别）
- 支付合规（实名认证）
- 文化审查（物品命名避免敏感）

### 7.2 Steam 全球发布

- ESRB/PEGI 年龄分级
- 各国税务
- GDPR（欧盟数据保护）
- 退款政策对齐 Steam

### 7.3 知识产权

- 游戏标题商标注册
- 英雄形象版权
- 音乐授权

## 九、Demo 阶段商业化

**Demo 阶段不涉及任何付费**：
- Demo 完全免费
- 无内购入口
- 无广告
- 只为验证玩法和收集反馈

Demo 的"商业价值"体现在：
- 产生 wishlist
- 口碑传播
- 用户调研数据
- 融资谈判砝码
