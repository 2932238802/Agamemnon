# 08 · AI 设计

> 本文档定义单机 Demo 阶段的 AI 行为系统。

---

## 一、AI 的定位

### 1.1 AI 的作用

1. **Demo 阶段**：替代人类对手，验证玩法
2. **正式版**：补位不足的多人房间
3. **练习模式**：新手学习 / 高手试验新策略

### 1.2 AI 设计原则

- **可信度**：AI 行为要像"人类"，而非完美机器
- **可调性**：通过参数调整难度，不重写代码
- **多样性**：不同 AI 表现出不同"性格"
- **性能**：单机 Demo 里 3 个 AI 同时计算，要快

## 二、AI 参数体系

### 2.1 核心参数

每个 AI 由 4 个参数定义"性格"：

```
AI {
  name:            名字
  hero:            使用的英雄（随机或指定）

  // 性格参数（0.0 ~ 1.0）
  aggressiveness:  激进度       （影响出价倾向）
  confidence:      自信度       （小样本敢不敢估）
  deception:       欺诈倾向     （出价扰动，Demo 先不用）
  skill:           估值精度     （误差大小，决定难度）
}
```

### 2.2 参数说明

#### `aggressiveness` 激进度 (0.0 ~ 1.0)
影响出价金额相对于估值的偏移：
```
final_bid = estimate × (0.9 + aggressiveness × 0.4)

  aggr=0.0 → 出价=估值×0.9  (保守，爱捡漏)
  aggr=0.5 → 出价=估值×1.1  (略激进)
  aggr=1.0 → 出价=估值×1.3  (极激进)
```

#### `confidence` 自信度 (0.0 ~ 1.0)
影响揭露率低时敢不敢大胆出价：
```
if revealed_ratio < 0.05:  # 揭露率 < 5%
    if confidence < 0.5:
        估值置信度低 → 主动压低出价 20~50%
    else:
        仍按正常估值出价
```

#### `skill` 估值精度 (0.0 ~ 1.0)
影响估值的随机误差：
```
error_margin = (1 - skill) × 0.3  # 最大 30% 误差
estimate *= random(1 - error_margin, 1 + error_margin)

  skill=0.3 → ±21% 误差  (新手 AI)
  skill=0.7 → ±9% 误差   (老手 AI)
  skill=1.0 → 无误差     (神级 AI，仅压测用)
```

#### `deception` 欺诈倾向 (Demo 阶段暂不启用)

## 三、预设 AI 档位

### 3.1 档位一览

Demo 阶段提供 4 档 AI，让玩家选择难度：

| 难度 | AI 名称 | aggr | conf | skill | 描述 |
|------|---------|------|------|-------|------|
| 🟢 简单 | 新手 Tom | 0.3 | 0.4 | 0.3 | 出价保守，经常估偏 |
| 🟡 中等 | 老将 Bob | 0.5 | 0.6 | 0.6 | 中规中矩的对手 |
| 🟠 困难 | 赌王 Alex | 0.9 | 0.8 | 0.7 | 激进，爱前期抢拍 |
| 🔴 极难 | 学霸 Emma | 0.4 | 0.9 | 0.9 | 精准稳健，难缠 |

### 3.2 Demo 默认配置

单机 Demo 进入一局：
- 玩家 = 1 个
- AI 1 = Tom（简单）
- AI 2 = Bob（中等）
- AI 3 = Alex（困难）

这样能让玩家感受不同风格的对手。

## 四、AI 决策流程

### 4.1 完整流程图

```
  ┌─────────────────────┐
  │ 回合开始             │
  └──────────┬──────────┘
             ↓
  ┌─────────────────────┐
  │ 1. 应用英雄被动      │ 系统自动执行
  │    揭露新格子        │
  └──────────┬──────────┘
             ↓
  ┌─────────────────────┐
  │ 2. 决定是否使用主动  │ 根据 CD 和策略
  └──────────┬──────────┘
             ↓
  ┌─────────────────────┐
  │ 3. 估算仓库总价值    │ 基于已揭露信息
  └──────────┬──────────┘
             ↓
  ┌─────────────────────┐
  │ 4. 决定出价          │ 考虑回合倍率、性格
  └──────────┬──────────┘
             ↓
  ┌─────────────────────┐
  │ 5. 提交出价          │ 带一点"思考延迟"
  └─────────────────────┘
```

### 4.2 各步骤详细逻辑

#### 步骤 1：揭露（被动自动）
- 由系统根据英雄被动规则自动揭露
- AI 不需要决策

#### 步骤 2：主动技能使用
```
IF 主动技能在 CD:
    不使用
ELSE:
    根据英雄类型选择：
      占卜师 → 选择已揭露物品"聚集区"附近的盲格 (扩大已知区)
      鹰眼   → 随机选一列 (最大化覆盖)
      学者   → 在"信息量少"的回合使用盘点
```

#### 步骤 3：估算仓库总价值
```
function estimate_total(ai):
    known_value = 0
    for cell in ai.revealed_cells:
        item = cell.item
        level = cell.reveal_level
        estimated_item_value = estimate_item(item, level, ai.skill)
        known_value += estimated_item_value

    if len(ai.revealed_cells) < 20:
        # 揭露太少，用先验信息
        return prior_average(ai.confidence)

    revealed_ratio = len(ai.revealed_cells) / 2000
    linear_estimate = known_value / revealed_ratio

    # 加入误差
    error_margin = (1 - ai.skill) * 0.3
    final_estimate = linear_estimate * random(1-error, 1+error)

    return final_estimate
```

#### 步骤 4：决定出价
```
function decide_bid(ai, round):
    estimate = estimate_total(ai)
    round_multiplier = get_round_multiplier(round)  # 2.0, 1.6, 1.3, 1.1, 1.0

    # 基础出价 = 估值 × 激进度调整
    base_bid = estimate * (0.9 + ai.aggressiveness * 0.4)

    # 考虑回合倍率：前期倍率高，不敢出太高
    if round <= 2 and ai.confidence < 0.7:
        # 低自信 AI 前期观望
        base_bid *= 0.6

    # 置信度影响：信息少的时候降低出价
    if revealed_ratio < 0.05 and ai.confidence < 0.5:
        base_bid *= 0.7

    # 随机扰动
    final_bid = base_bid * random(0.95, 1.05)

    # 5% 概率弃拍（模拟犹豫）
    if random() < (0.15 - ai.aggressiveness * 0.1):
        return 0

    return int(final_bid)
```

#### 步骤 5：提交（带延迟）
```
提交前等待 2~8 秒随机延迟
(防止 AI 瞬间提交，让玩家感觉"AI 在思考")
```

## 五、单物品估值函数

### 5.1 按揭露层级估值

```
function estimate_item(item, level, skill):
    (w, h) = item.size

    if level == L4:
        return item.true_value  # 精确值

    if level == L3:  # 只知品质
        # 根据品质中位数
        median = QUALITY_MEDIAN[item.quality]  # e.g. 紫=1500
        volume_multiplier = (w * h) / 4  # 以 2×2 为基准
        estimated = median * volume_multiplier
        error = (1 - skill) * 0.3
        return estimated * random(1-error, 1+error)

    if level == L2:  # 只知类别
        # 类别的平均值（跨所有品质）
        avg = CATEGORY_AVG[item.category]
        volume_multiplier = (w * h) / 4
        estimated = avg * volume_multiplier
        error = (1 - skill) * 0.5  # 误差更大
        return estimated * random(1-error, 1+error)

    if level == L2+L3:  # 类别+品质都知道
        median = CATEGORY_QUALITY_MEDIAN[item.category][item.quality]
        volume_multiplier = (w * h) / 4
        estimated = median * volume_multiplier
        error = (1 - skill) * 0.15  # 误差最小（非 L4 级）
        return estimated * random(1-error, 1+error)

    if level == L1:  # 只知存在性
        # 按全仓库平均价值估算
        estimated = GLOBAL_AVG_VALUE * (w * h)
        error = (1 - skill) * 0.7  # 误差很大
        return estimated * random(1-error, 1+error)
```

### 5.2 常量表

```
QUALITY_MEDIAN = {
    白: 20,      绿: 60,       蓝: 300,
    紫: 1500,    黄: 6000,     红: 30000
}

GLOBAL_AVG_VALUE = 80  // 全仓库物品平均值

CATEGORY_AVG = {
    武器: 70, 防具: 80, 艺术: 120, 器皿: 60,
    书籍: 50, 饰品: 40, 家具: 150, 消耗: 30
}
```

（具体数值会在平衡测试中调整）

## 六、AI 的"人性化"细节

### 6.1 思考延迟

```
delay = random(2, 8) seconds
high_confidence AI → 延迟短 (2~5s)
low_confidence AI → 延迟长 (4~8s)

UI 显示："AI_2 思考中..."
```

### 6.2 偶尔犯错

```
每回合 5% 概率触发"失误"：
  - 出价偏离正常值 ±30%
  - 模拟人类的分心/手滑

high_skill AI → 失误率 2%
low_skill AI → 失误率 10%
```

### 6.3 性格惯性

```
AI 一局内保持性格一致：
  激进 AI 不会突然变保守
  保守 AI 不会突然疯狂加价
  (除非触发失误)
```

### 6.4 针对性策略（进阶）

```
如果玩家前面连赢 2 局：
  AI 变得更警惕 → 估值误差 -5%

如果玩家前面连输 2 局：
  AI "放水" → 估值误差 +5%

设计意图：防止玩家体验过于枯燥的连胜/连败
（可选，非必需）
```

## 七、AI 使用主动技能的时机

### 7.1 技能冷却管理

```
AI 记录每个技能的 last_used_round
decision_to_use_active(ai, round):
    if round - ai.last_used_round < ai.active_cd:
        return False

    # 根据英雄类型决定时机
    switch ai.hero:
        case 占卜师:
            # 有大件但未 L4 揭露 → 使用
            if has_undisclosed_large_item():
                return True
        case 鹰眼:
            # 揭露率 < 3% 的时候使用
            return revealed_ratio < 0.03
        case 学者:
            # 出价前一回合使用
            return round % 2 == 0
```

### 7.2 目标选择

```
占卜师的"天眼"目标选择：
  优先级 1: 已揭露 L2 的大件 (尺寸 >= 3×3)
  优先级 2: 已揭露 L3 但未 L4 的高品质
  优先级 3: 当前聚集区的边界盲格

鹰眼的"列扫描"目标：
  选择当前揭露最少的列
  (最大化新信息量)
```

## 八、AI 的输掉/赢下处理

### 8.1 AI 不使用心理战（Demo 阶段）

- AI 不故意出高价逼迫其他 AI 掉分
- 纯粹按自己的估值和性格出价
- 不观察其他玩家的出价（单机 Demo 里其他 AI 看不到彼此）

### 8.2 胜负对 AI 无影响

- AI 没有"目标上分"的动机
- 它只是模拟一个"根据信息出价的玩家"
- 玩家的胜负完全取决于自己的能力

### 9.2 性能考虑

```
单局 10 回合 × 3 个 AI = 30 次决策
```

## 十、AI 测试建议

### 10.1 平衡性测试

```
跑 1000 局 AI vs AI：
  4 个 Alex 互打 → 胜率应接近 25% ± 5%
  1 Tom + 3 Alex → Tom 胜率应明显 < 25%
  1 Emma + 3 Tom → Emma 胜率应明显 > 25%
```

### 10.2 估值准确性测试

```
对同一仓库跑 1000 次 AI 估值：
  Emma (skill=0.9) → 平均误差 < 15%
  Tom (skill=0.3) → 平均误差 > 35%
```

### 10.3 真人对抗测试

```
让 10 位内部玩家对抗 3 级 AI：
  面对 Tom → 赢率应 > 50%
  面对 Bob → 赢率应接近 25~35%
  面对 Alex/Emma → 赢率应 < 25%
```
