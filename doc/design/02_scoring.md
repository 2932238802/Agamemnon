# 02 · 评分与排位系统

> 本文档定义《Agamemnon》的排位分机制、段位系统和赛季设计。

---

## 一、核心理念

> **排位分 = 估值精度的量化体现**
>
> 不看金币，不看赢了多少件，只看你估得准不准。

### 关键特性

| 特性 | 说明 |
|------|------|
| 零和 | 单局内 4 人分数变动总和 = 0 |
| 可量化 | 估值偏差百分比直接映射为分数 |
| 可预测 | 玩家能预判"我这局大概 +/- 多少" |
| 无掉线惩罚（Demo 阶段） | 联机版再考虑 |

---

## 二、单局分数变动公式

### 2.1 核心变量

```
V    = 仓库真实总价值
P_A  = 拍下玩家 A 的出价
base = 基础分变动系数（默认 30）
```

### 2.2 拍卖成功的结算

#### 拍下者 A 的分数变动

```
偏差率 e_A = (V - P_A) / V

  e_A > 0  →  A 捡漏了（出价低于真值）  →  上分
  e_A = 0  →  A 精准估值                 →  不变
  e_A < 0  →  A 砸手了（出价高于真值）  →  掉分

Δ_A = base × e_A
```

**为防止极端值，设置上下限**：
```
Δ_A ∈ [-base, +base]  = [-30, +30]
```

#### 其他 3 位玩家（BCD）

```
Δ_其他 = -Δ_A / 3
```

#### 验证：零和性
```
Δ_A + Δ_B + Δ_C + Δ_D
  = Δ_A + 3 × (-Δ_A/3)
  = Δ_A - Δ_A
  = 0  ✅
```

### 2.3 流拍的结算

**情况 A：中途某回合流拍，进入下一回合**
- 不做任何分数结算
- 等最终结果（某回合拍下 / 10 回合和局）

**情况 B：10 回合全流拍**
- 所有人 0 变动（友好型设计）
- UI 提示"本局情报不足，排位分未变动"

## 三、分数计算示例

### 示例 1：精准捡漏

```
仓库真值 V = 30,000
玩家 A 拍下，P_A = 25,000

e_A = (30000 - 25000) / 30000 = 16.67%
Δ_A = 30 × 0.1667 = +5 分
Δ_B = Δ_C = Δ_D = -1.67 分（约 -2 分，UI 四舍五入）

分数结果：
  A: +5
  B: -2
  C: -2
  D: -1  （零和取整后分配）
```

### 示例 2：严重砸手

```
仓库真值 V = 10,000
玩家 A 拍下，P_A = 20,000（高估 100%）

e_A = (10000 - 20000) / 10000 = -100%
Δ_A = 30 × (-1.0) = -30 分（触顶）
其他三人 = +10 分

分数结果：
  A: -30
  B: +10
  C: +10
  D: +10
```

### 示例 3：完美估值

```
仓库真值 V = 18,000
玩家 A 拍下，P_A = 18,000

e_A = 0
Δ_A = 0
其他三人 = 0

分数结果：
  所有人: 0
```

## 四、一局总分变动

### 4.1 单局分数变动范围

由于一局最多只结算一次（最多一次拍下），理论上：

```
单人单局变动范围: [-30, +30] 分
```

### 4.2 加入"参与度加成"（可选）

为了鼓励玩家积极出价而非总是保守：

```
若玩家本局从未提交过有效出价（全弃拍）:
  额外 -3 分（惩罚消极）
```

此机制**Demo 阶段不启用**，后期可调。

## 五、段位系统

### 5.1 段位划分

| 段位 | 分数区间 | 图标 | 玩家占比目标 |
|------|---------|------|-------------|
| 🟫 青铜 | 0 ~ 999 | 🥉 | 25% |
| ⬜ 白银 | 1000 ~ 1499 | 🎖️ | 25% |
| 🟡 黄金 | 1500 ~ 1999 | 🏅 | 20% |
| 🔷 铂金 | 2000 ~ 2499 | 💠 | 15% |
| 💎 钻石 | 2500 ~ 2999 | 💎 | 10% |
| 🔴 大师 | 3000 ~ 3499 | 🌟 | 4% |
| 🟣 宗师 | 3500+ | 👑 | 1% |

### 5.2 初始分

```
新玩家起始分：1000（白银起步）
定级赛（前 10 局）：分数变动 ×2 以加速定位
```

### 5.3 每段位内细分（钻石以下）

```
青铜 I    0~199
青铜 II   200~399
青铜 III  400~599
青铜 IV   600~799
青铜 V    800~999
（白银/黄金/铂金同理）
```

钻石及以上**不再细分**，按绝对分数排名。

### 5.4 升降段保护机制

```
升段保护：
  首次晋级新段位后，掉分时有 1 次免掉段（回到段位底线）

降段压力：
  分数低于当前段位下限 → 进入"降段赛"
  降段赛期间（3 局）保持当前段位
  3 局中回到段位内 → 保级
  3 局后仍低于 → 正式降段
```

## 六、赛季系统

### 6.1 赛季基础

```
赛季长度：3 个月
赛季更替：
  1) 分数软重置：current_score = 1000 + (current_score - 1000) × 0.3
     例：2500 分 → 1000 + 1500×0.3 = 1450
  2) 发放上赛季段位奖励
  3) 所有人重新定级（前 3 局分数变动 ×1.5）
```

### 6.2 赛季主题

每个赛季一个主题，影响：
- 仓库视觉风格（如"海盗赛季"的木桶风、"宫廷赛季"的精致风）
- 物品池倾斜（主题相关物品出现率 +）
- 限定皮肤 / 头像框 / 表情

**示例主题**：
- S1：古董珍玩（默认风格）
- S2：末世废墟
- S3：星际太空
- S4：东方瑰宝

### 6.3 赛季奖励

| 达到的最高段位 | 奖励 |
|---------------|------|
| 青铜 | 赛季纪念头像 |
| 白银 | 纪念头像 + 50 金币代币 |
| 黄金 | 头像 + 代币 + 头像框 |
| 铂金 | 头像 + 代币 + 头像框 + 专属动作 |
| 钻石 | + 限定仓库主题 |
| 大师 | + 限定英雄皮肤 |
| 宗师 | + 名字金色特效 |

## 七、排行榜

### 7.1 排行榜类型

| 榜单 | 说明 |
|------|------|
| 全球段位榜 | 总分排名（仅显示 Top 1000） |
| 地区榜 | 按服务器分区 |

### 7.2 排行榜奖励

- 周榜 Top 10：周末双倍经验
- 赛季榜 Top 100：限定金色边框
- 赛季榜 Top 10：名字永久标记 "S1 宗师"

## 八、MMR vs 显示分数（进阶）

### 8.1 内部 MMR（隐藏分）

```
真实匹配用的是隐藏 MMR
显示的排位分是"美化版"
差距较大时显示分涨幅 > MMR 涨幅（新玩家爬坡）
差距较小时两者一致
```

**Demo 阶段**：MMR = 显示分（不做分离）
**上线后**：考虑分离以优化匹配体验

### 8.2 匹配算法基础

```
玩家 X 匹配逻辑：
  寻找 MMR 差距 ≤ 150 的其他 3 人
  找不到 → 扩大到 300
  仍找不到 → 扩大到 500（最多等 60s）
  超时 → 用 AI 补位
```

## 九、反滥用机制

### 9.1 挂机检测
- 连续 3 回合完全无操作 → 标记"挂机"
- 标记 3 次/日 → 扣 50 分 + 匹配降权 1 小时

### 9.2 合作作弊（预防）
- 4 人中有 2 人来自同 IP → 显示"熟人局"
- 熟人局分数变动 ×0.5

### 9.3 段位保护
- 连败 3 局 → 第 4 局变动 ×0.7（防挫败）
- 连胜 3 局 → 第 4 局变动 ×0.7（防速通）
