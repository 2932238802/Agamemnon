# 05 · 英雄系统（占位文档）

> ⚠️ 本文档为**占位框架**，详细英雄设计待后续细化。

---

## 一、设计方向（已确定）

### 1.1 英雄的核心作用

英雄是玩家**获取信息的独特方式**。不同英雄 = 不同的情报路线。

### 1.2 设计原则

1. **无万能英雄**：每个英雄都有短板
2. **相克关系**：英雄之间有策略克制
3. **特色明显**：一眼能看出每个英雄的风格
4. **易学难精**：新手用占卜师就能玩，高手用骗子才能发挥
5. **数值平衡**：每回合能"获得的信息总价值"接近

### 1.3 英雄的构成

```
英雄 Hero {
  name:          名称
  title:         称号
  description:   背景故事
  icon:          头像

  passive:       被动技能（每回合自动触发）
  active:        主动技能（手动释放，有 CD）
  active_cd:     主动冷却回合数

  play_style:    风格标签（稳健/激进/诡诈/范围/精准...）
  difficulty:    上手难度（1~5 星）
}
```

## 二、首批英雄（概念草案）

> 以下为**初步构想**，数值和具体效果待后续平衡测试。

### 🔮 占卜师 Oracle
- **风格**：稳定、全面
- **被动**：每回合随机揭露 5 格的品质（L3）
- **主动**：指定 1 格完全揭露（L4），CD 2 回合
- **难度**：⭐ 新手友好
- **短板**：揭露位置随机，信息不聚焦

### 🦅 鹰眼 Eagle
- **风格**：大范围扫描
- **被动**：每回合揭露一整行的品质（L3）
- **主动**：指定一整列揭露存在性（L1），CD 3 回合
- **难度**：⭐⭐
- **短板**：信息广但浅

### 📚 学者 Scholar
- **风格**：少而精 + 统计专家
- **被动**：每回合随机揭露 3 格的完整信息（L4）
- **主动**：查看仓库品质分布（如"白 120 / 绿 50 / 蓝 20 / 紫 5 / 黄 2 / 红 1"），CD 2 回合
- **难度**：⭐⭐⭐
- **短板**：具体物品揭露少

### 🗡 盗贼 Thief（后续）
- **风格**：广撒网 + 偷看
- **被动**：每回合揭露 10 格的存在性（L1）
- **主动**：偷看对手的 3 格揭露，CD 3 回合
- **难度**：⭐⭐⭐⭐
- **短板**：信息精度低

### 🎭 骗子 Trickster（后续）
- **风格**：诡诈 + 欺骗
- **被动**：每回合揭露 3 格 L4，但有 1 格是假信息
- **主动**：向指定对手投放 1 个假 L4 信息，CD 2 回合
- **难度**：⭐⭐⭐⭐⭐ 高手向
- **短板**：自己也要辨别真假

### 💰 商贾 Merchant（后续）
- **风格**：元信息 + 出价优势
- **被动**：每回合获得 1 条宏观线索（"本仓库价值偏高/中/偏低"）
- **主动**：在平局时抢先赢得仓库，CD 3 回合
- **难度**：⭐⭐⭐
- **短板**：具体物品揭露能力弱

## 三、Demo 阶段的英雄

Demo 阶段先做 **3 个基础英雄**：
- ✅ 占卜师 Oracle

这 3 个已经能覆盖"点揭露/面揭露/精确揭露"三种主要风格，足够验证核心玩法。

### 4.2 设计讨论的开放问题

1. **英雄是否有等级/熟练度系统？**
   - 选项 A：纯外观收集，不影响强度
   - 选项 B：每个英雄用得多能解锁"变体技能"（会增加平衡复杂度）

2. **能不能"同一局两人选同一英雄"？**
   - 选项 A：允许（简化匹配）
   - 选项 B：禁止（增加多样性）
   - 建议 A，因为英雄的被动是对**自己的仓库视图**起作用，不会重复

3. **英雄解锁机制**
   - 选项 A：全免费全开放
   - 选项 B：前 3 个免费，其余通过游戏币/任务解锁
   - 选项 C：买断制下全部开放
   - 建议 C（本游戏走买断制）
